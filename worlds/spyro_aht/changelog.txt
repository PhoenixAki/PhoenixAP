2.2.0 (PAL support, redesigned shop & goal systems, traps, and more)
- Added support for PAL GC version of game.
- Shop system redesigned to use `shop_logic` instead of `gem_logic`.
  - `shop_logic = ordered` works identically to `gem_logic = true`.
  - `shop_logic = unordered` is a replacement for `gem_logic = false` which assumes the player will buy items in order, but won't restrict them from doing otherwise.
  - Also, added `shop_item_count` for customizing how many shop items there are.
* Logging system redesigned to be a single choice of level of detail. Warning messages from YAML issues are now always logged.
* The goal system has been expanded (customizing how many checks per goal, new minigame and elder goals, reworked `/check_goal`)
* `auto_corrections` expanded to `fix_minor` and `fix_major`. Minor fixes are things that are relatively inconsequential, major have a more notable impact on the seed.
* Added support for 4 traps (Spam Call, Reverse Controls, Gem Tax, and Damage Sparx).
- Refactored/organized significant chunks of the codebase to be more smartly designed, particularly the item creation process.
- Client commands have slightly better error checking now. Also added `/costs` as a convenience command that outputs various costs separately from `/list_options`.
- Made an updated logic spreadsheet which lists every region and location access rule.
- Map icons now render as red = unreachable, yellow = reachable, green = checked.
- Every location was renamed to be less verbose, and they have a new ID mapping system which makes some features *way* easier to code.
- Partially undid the custom sorting of locations in the tracker page. Locations are now sorted first in order of vanilla game levels, then alphabetically by logical region, then alphabetically by location.
- Added "Sent <item> to <player>" notifications in-game. None of us have any idea why they weren't there already, either...also added a small Easter egg when you receive a specific type of item from yourself :slight_smile:
- Added 270 Stormy Beach gems to gem logic that were missed.
- `hint_boss_rewards` now hints all boss locations, not just the breath rewards.
- Added location groups for Light Gem doors and gadgets.
- Fixed an inconsequential logic bug in Magma Falls Bottom.

2.1.0 (various misc. things)
- Fixed `vanilla_minigame_rewards` not working for turret minigames.
- Fixed a missing glide requirement in Dragonfly Falls connecting the end of the level back to the start.
- Improved error handling in /check_goal.
- Removed glide requirement from the locked chest in the entry area of Dragonfly Falls.
- Added `automatic` setting to `boss_lair_forcing` which forces all goal bosses (if any are part of goal) to have collectively the highest cost(s).
- Expanded location groups to include per-level and per-realm groups for Dark Gems, Dragon Eggs, Light Gems, Fireworks, and Locked Chests. Some other misc. groups added as well (such as "Starter Checks").
- Tweaked `movement_randomization` to allow for individual toggling of each ability, instead of it being all or nothing.
- Renamed `starting_breath` -> `starting_breaths` and redesigned it to allow for starting with multiple breaths, none, or a random one if list is empty.
- `starting_realms` was made to match the above behavior i.e. random starting breath if list is empty. Neither requires `auto_corrections` to be set to `fix`.
- "Generics" filler item selection process improved to be more uniform. Each will be picked once each before doubling any up, and same for tripling, quadrupling, etc.

2.0.2 (notification hotfix)

2.0.1 (hotfixes + small option addition)
- Game mod update: new mod versioning system (now uses a major and minor version e.g. 13.1 or 14.0).
  - Client has an improved ability to recognize version mismatches, as a result. It will output errors when the major mod version doesn't match, and softer warnings when using an outdated minor version.
  - Major version is bumped whenever client compatibility is broken i.e. new addresses. Minor version is bumped for mod back-end changes that the client can still work with. Some exceptions apply (such as renaming 13.2 to 14.0 semi-arbitrarily). 
- New option: death_link_amnesty. Players can choose how many in-game deaths it takes for a single DeathLink death to be sent.
- Fix: Game mod updated to prevent charging underwater if player doesn't have charge as a movement ability.
  - This overrides vanilla game behavior because AHT AP logic rules were inadvertently designed with this misunderstanding in mind. This was determined to be the simpler fix (instead of redesigning dozens of logic rules).
- Fix: hint_minigame_rewards and hint_boss_rewards were not working due to an overzealous micro-optimization attempt which backfired :)
- Fix: Game mod now reports the right gem amounts on the pause menu when in minigames.

2.0.0 (this is a lot)
- Project things:
	- Primary project developer has switched from Maya (XuaThaGrate) to Phoenix (PhoenixAki) as of 2.0. Hello hi that's me ^.^
	- Module renamed from `spyro-aht` to `spyro_aht`.
	- Added brand-new wiki containing any and all information pertaining to AHT AP.
	- Added an open-source license to the project. In short, "do what you want with the code but don't sell it or profit off of it."

- Major Feature #1: "gem logic" system for use with shop_randomization:
	- This comes bundled with a number of new options: gem_logic, blink_gems, non_blink_enemies, other_gems, and double_gems.
	- If gem_logic is enabled, a series of logical events will map out your access to gems, and this is used to space out shop item purchases through the seed.
	- If gem_logic is disabled, the randomized shop will work similarly to in the past, except prices are determined by the new options instead of from a random range.

- Major Feature #2: open_world_mode:
	- This mode sets the various Moneybags shop pads to be unlocked by various Archipelago items. Can be set to start with them all unlocked, each one unlocks individually, they unlock fully per level, etc.
	- Each setting is fully supported logically and makes a dramatic impact on the "feel" of playing AHT AP. Players are expected to take advantage of teleporting around from shop pad to shop pad.

- Client Things:
	- The client now has full Universal Tracker integration, including YAML-less tracking and proper reporting of randomized settings.
	- 2 new commands: /check_goal (gives goal information) and /add_item (adds items to game memory directly, meant for debugging/testing).
	- Custom deathlink messages now send when the player dies, depending on death animation.
	- Client now enforces the right version of the game mod when connecting.

- Mid-sized Things:
	- There are now 10 different goals that can be chosen in any combination desired. boss_lair_forcing was introduced to allow for the now-previously default behavior of forcing your goal boss to have the most expensive lair.
	- Realm access system overhauled. starting_realms decides which realms to start with access to, and their access card(s) are added to the starting inventory.
	- New generation settings, including logging_level (logging system) and auto_corrections (automatic fixing of YAML issues).
	- 4 types of filler items can now be enabled/disabled individually: Dragon Eggs, Beath Bombs, Gem Packs, and a new category "Generics", which do nothing, but have humorous names.

- Smaller Things:
	- Various game mod additions, including rendering of map icons on all maps instead of just the one you're currently in, and numerous other small/mid-sized things.
	- Expanded location groups to also have all bosses, dark gems, dragon eggs, light gems, locked chests, fireworks, and minigames.
	- 4 new quality of life/cosmetic options: pause_menu_patch, hint_shop_items, hide_shop_item_names, and teleport_across_realms.
	- Starting breath can now be any of the 4 breaths, or none. This replaces old system which was none, fire, or a random choice.
	- Condensed the various minigame randomization options into a single vanilla_minigame_rewards option.
	- Renamed randomize_movement to movement_randomization to have similar semantics to shop_randomization.
